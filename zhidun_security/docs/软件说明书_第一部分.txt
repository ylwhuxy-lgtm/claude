第一章  引言
===============================================================

1.1 编写目的

本说明书是《智盾网络安全态势感知与智能防御系统 V1.0》（以下
简称"本系统"或"智盾系统"）的配套技术文档，旨在为用户提供
系统的功能说明、操作指南和技术参考。

本说明书的主要读者包括：
(1) 系统管理员：负责系统的安装、配置和日常维护；
(2) 安全分析师：使用系统进行威胁监控、分析和响应；
(3) 安全运维人员：负责安全事件的处置和应急响应；
(4) 管理层人员：查看安全态势报告和决策分析数据；
(5) 审计人员：审查系统操作日志和安全事件记录。

1.2 适用范围

本说明书适用于智盾网络安全态势感知与智能防御系统 V1.0 版本。
本系统适用于以下场景：
(1) 企事业单位内部网络安全监控；
(2) 关键信息基础设施安全防护；
(3) 数据中心网络安全态势感知；
(4) 云计算环境的安全监控与防御；
(5) 政府机关网络安全保障。

本系统可部署在企业内部网络环境中，对网络流量进行实时采集和
分析，自动检测各类网络安全威胁，并提供可视化的安全态势展示
和自动化的威胁响应处置能力。

第二章  软件概述
===============================================================

2.1 软件名称与版本

软件全称：智盾网络安全态势感知与智能防御系统
软件简称：智盾安全系统
英文名称：ZhiDun Network Security Situational Awareness
          and Intelligent Defense System
版 本 号：V1.0
开发语言：Python 3.9+
软件类型：应用软件 / 信息安全类

2.2 软件用途

随着网络安全威胁日益复杂和多样化，传统的基于规则的安全防护
手段已难以应对高级持续性威胁(APT)、零日攻击等新型攻击方式。
本系统旨在通过人工智能和大数据分析技术，构建一套集"监测、
检测、分析、响应、展示"五位一体的网络安全综合防护平台。

本系统的主要用途包括：

(1) 网络安全态势实时感知
    通过对网络流量的持续监控和深度分析，实时掌握网络安全
    整体态势，为安全决策提供数据支撑。

(2) 多维度威胁智能检测
    融合签名检测、行为分析和机器学习三种检测技术，实现对
    已知威胁和未知威胁的全面检测覆盖。

(3) 安全事件自动化响应
    根据预设的响应策略，对检测到的安全威胁进行自动化处置，
    包括IP封禁、流量限速、主机隔离等，缩短事件响应时间。

(4) 威胁情报关联分析
    聚合多源威胁情报，与实时检测结果进行关联分析，提升
    威胁识别的准确性和情报利用效率。

(5) 安全态势可视化展示
    通过直观的安全仪表盘，以图表、热力图、时间线等多种
    形式展示网络安全态势，辅助安全运营决策。

2.3 目标用户

本系统面向以下类型的组织和用户：

(1) 政府机关和事业单位
    - 网信办、公安等网络安全监管部门
    - 各级政府部门信息中心

(2) 关键信息基础设施运营者
    - 电力、交通、金融、水利等行业
    - 通信运营商和互联网企业

(3) 大中型企业
    - 企业安全运营中心(SOC)
    - IT运维和安全管理团队

(4) 安全服务提供商
    - 托管安全服务商(MSSP)
    - 安全咨询和评估机构

功能模块一：用户认证与权限管理
- 用户注册、登录、登出
- 基于角色的访问控制(RBAC)，支持6种角色
- 密码安全策略（强度校验、定期更换）
- 登录失败锁定机制（5次失败自动锁定）
- 多因素认证(MFA)支持
- IP白名单登录限制
- 完整的操作审计日志

功能模块二：安全态势仪表盘
- 全局安全评分实时展示（0-100分）
- 风险等级可视化（低危/中危/高危/严重/紧急）
- 威胁热力图（源-目标网段矩阵）

功能模块三：网络流量监控
- 多网络接口并行流量采集
- 以太网帧、IP、TCP、UDP多层协议深度解析
- 网络流(Flow)自动跟踪与管理
- 实时流量速率统计（PPS/BPS）
- 协议分布分析
- Top Talker排名
- 入站/出站流量比例分析
- 过期流自动清理

功能模块四：威胁检测引擎
- 签名检测：内置8类攻击签名规则

第四章  安装与部署
===============================================================

4.1 安装准备

在安装本系统前，请确认以下准备工作已完成：

(1) 检查操作系统版本
    执行命令: cat /etc/os-release
    确认操作系统为 Ubuntu 20.04+ 或 CentOS 7+

(2) 检查Python版本
    执行命令: python3 --version
    确认Python版本为3.9或更高

(3) 安装Python 3.9+（如未安装）
    Ubuntu系统:
      sudo apt update
      sudo apt install python3.9 python3.9-venv python3-pip

    CentOS系统:
      sudo yum install python39 python39-pip

(4) 安装PostgreSQL数据库
    Ubuntu系统:
      sudo apt install postgresql postgresql-contrib
      sudo systemctl start postgresql
      sudo systemctl enable postgresql

(5) 安装Redis缓存
    Ubuntu系统:
      sudo apt install redis-server
      sudo systemctl start redis-server
      sudo systemctl enable redis-server

(6) 创建系统用户
    sudo useradd -m -s /bin/bash zhidun
    sudo passwd zhidun

4.2 系统安装

步骤一：获取系统安装包
    将系统安装包上传至服务器，并解压到安装目录:
    sudo mkdir -p /opt/zhidun
    sudo tar -xzf zhidun_security-v1.0.tar.gz -C /opt/zhidun
    sudo chown -R zhidun:zhidun /opt/zhidun

步骤二：创建Python虚拟环境
    cd /opt/zhidun
    python3 -m venv venv
    source venv/bin/activate

步骤三：安装Python依赖
    pip install -r requirements.txt

步骤四：创建必要目录
    mkdir -p /opt/zhidun/logs
    mkdir -p /opt/zhidun/data
    mkdir -p /opt/zhidun/reports
    mkdir -p /opt/zhidun/certs
    mkdir -p /opt/zhidun/forensics

步骤五：生成SSL证书（生产环境请使用正式证书）
    openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
      -keyout /opt/zhidun/certs/server.key \
      -out /opt/zhidun/certs/server.crt \
      -subj "/CN=zhidun.local"

步骤六：验证安装
    python3 -c "from config.settings import SystemConfig; print('安装成功')"

4.3 数据库配置

步骤一：创建数据库和用户
    sudo -u postgres psql
    CREATE USER zhidun_admin WITH PASSWORD 'your_password';
    CREATE DATABASE zhidun_security OWNER zhidun_admin;
    GRANT ALL PRIVILEGES ON DATABASE zhidun_security TO zhidun_admin;
    \q

步骤二：初始化数据库表结构
    python3 -m utils.db_init

步骤三：验证数据库连接
    python3 -c "
    from config.settings import DatabaseConfig
    db = DatabaseConfig(password='your_password')
    print(f'数据库连接URL: {db.connection_url}')
    print('数据库配置验证成功')
    "

        "promiscuous_mode": true,
        "packet_batch_size": 1000
    },
    "detection": {
        "mode": "hybrid",
        "max_workers": 8,
        "anomaly_threshold": 0.85,
        "correlation_window": 300
    },
    "response": {
        "auto_block_enabled": true,
        "block_duration": 3600,
        "max_auto_blocks": 1000,
        "whitelist_ips": ["10.0.0.1"]
    },
    "dashboard": {
        "port": 8443,
        "ssl_enabled": true
    }
}

核心配置参数说明：

(1) capture.interfaces
    说明：要监控的网络接口列表
    默认值：["eth0"]
    取值范围：系统可用网络接口名称
    示例：["eth0", "eth1"]（多接口并行采集）

(2) detection.mode
    说明：检测模式
    默认值："hybrid"（混合模式）
    可选值："passive"（被动检测）、"active"（主动检测）、
           "hybrid"（混合检测，推荐）

(3) detection.anomaly_threshold
    说明：异常检测阈值，评分超过此值判定为异常
    默认值：0.85
    取值范围：0.0 ~ 1.0
    说明：值越低灵敏度越高但误报也越多，建议0.80~0.90

(4) detection.correlation_window
    说明：关联分析时间窗口（秒）
    默认值：300（5分钟）
    说明：在此时间窗口内的告警会被关联分析

(5) response.auto_block_enabled
    说明：是否启用自动封禁
    默认值：true
    说明：设为false时仅告警不自动封禁

(6) response.block_duration
    说明：默认封禁时长（秒）
    默认值：3600（1小时）
    取值范围：60 ~ 604800（1分钟到7天）

(7) response.whitelist_ips
    说明：IP白名单，白名单中的IP不会被自动封禁
    默认值：[]
    示例：["10.0.0.1", "192.168.1.100"]

(8) dashboard.port
    说明：Web仪表盘监听端口
    默认值：8443
    取值范围：1 ~ 65535
